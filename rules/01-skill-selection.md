# 01 - Skill Selection (enforcement summary of SKILLS.md)

- Skills come only from the registry in `SKILLS.md`. Match on section, then on "Pick when".
- Max 3 skills per section. Prefer the most specific skill. Do not stack two skills that solve the same problem.
- Platform firewall is absolute (see `SKILLS.md` section 1).
- Install only after the plan is written to `.agent/ACTIVE_SKILLS.md`.
- Read only installed skills that belong to the section in progress.
- If a skill's "Don't use when" applies, pick another or none.
- If the user explicitly names a skill, use it (still subject to the platform firewall).
- When a skill's instructions conflict with `DESIGN.md` or `rules/`, `DESIGN.md` and `rules/` win; mention the
  conflict to the user.
