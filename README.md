# skillstack

A **section-scoped skill library** for AI coding agents (built for Google Antigravity, works with any
agent that reads `AGENTS.md` / `SKILL.md`).

Instead of loading every skill into the agent's context, the agent:

1. Identifies the **platform** (`web`, `mobile`, `desktop`, `backend`),
2. Breaks the app into **sections** (hero, navigation, auth, offline sync, packaging ...),
3. Picks the **best 1-2 skills per section** from the registry,
4. **Installs only those skills** into the project (`.agent/skills/`),
5. Builds the section under the rules in `DESIGN.md`, `SKILLS.md` and `rules/`.

> **AI AGENT?** If you were given this repository URL, stop reading this file and read
> [`INSTALL_FOR_AGENTS.md`](./INSTALL_FOR_AGENTS.md) now.

## Use it (Antigravity)

Open your project folder in Antigravity and tell the agent:

```
Use https://github.com/<you>/skillstack to build: <what you want>. Platform: web|mobile|desktop|backend.
```

The agent clones it into `.agent/.skills-source/`, installs the baseline rules, then installs skills
just-in-time per section.

## Repository layout

```
AGENTS.md              operating contract (copied into your project)
GEMINI.md              pointer to AGENTS.md (for Gemini-based agents)
DESIGN.md              design law + design brief template (copied once, never overwritten)
SKILLS.md              selection protocol + registry of all skills
INSTALL_FOR_AGENTS.md  what an agent does when handed this URL
rules/                 engineering rules (workflow, quality gates, perf, a11y, security, media, structure)
platforms/             web.md / mobile.md / desktop.md / backend.md  (stack defaults + platform firewall)
skills/<platform>/<skill>/SKILL.md     web/ mobile/ desktop/ backend/ shared/
scripts/               install.mjs  validate.mjs  lib.mjs   (zero dependencies, Node >= 18)
templates/             SKILL.template.md
registry.json          machine-readable index (generated by validate.mjs)
```

## CLI

```bash
node scripts/install.mjs --list [--platform web]
node scripts/install.mjs --platform web --baseline --target ../my-app
node scripts/install.mjs --platform web --skills web-scroll-scrubbed-video --section hero --target ../my-app
node scripts/install.mjs --target ../my-app --remove web-seo-metadata
node scripts/validate.mjs        # lint skills + regenerate registry.json
```

Platform firewall: a `web` project can only install `web-*` and `shared-*` skills. A desktop app with a web UI
may opt in with `--allow-cross web`.

## Add a skill

1. Copy `templates/SKILL.template.md` to `skills/<platform>/<name>/SKILL.md`.
2. Add a row to the registry table in `SKILLS.md`.
3. Run `node scripts/validate.mjs`.

## Changing the agent folder

Antigravity reads workspace skills from `.agent/skills/`. If your version uses a different folder, change
`AGENT_DIR` in `scripts/lib.mjs`.

## Later: MCP

The registry is already machine-readable (`registry.json`). A tiny MCP server exposing `list_skills`,
`recommend_skills(section)` and `install_skill(name)` can wrap `scripts/lib.mjs` without changing the repo layout.
